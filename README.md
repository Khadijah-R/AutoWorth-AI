
# AutoWorth AI 🚗

An AI-powered used-car price estimation project built with machine learning.

## Overview

AutoWorth AI estimates a used car's market price based on its features. The goal is to help users assess whether a seller's asking price is reasonable.

## Features

- Used-car price prediction
- Machine learning model
- Interactive Streamlit application
- Model development and evaluation in Jupyter Notebook

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

## Project Files

- `app.py` — Streamlit application
- `AutoWorth_AI_Enhanced.ipynb` — Model development notebook
- `requirements.txt` — Python dependencies
- `.gitignore` — Files excluded from Git tracking

## Installation

Install the required dependencies:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
streamlit run app.py
```

The trained model and preprocessor must be available in the locations and filenames expected by the application.
